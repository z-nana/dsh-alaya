DSH Alaya 初始版本：原生工具接入 Alaya 3.1.0 的知识库、多角色、资料入库、记忆与维护功能。

下载 dsh-alaya-0.1.0.tgz 后，在下载目录执行：

```powershell
dsh plugin --profile web add ./dsh-alaya-0.1.0.tgz
```

需要 DSH 0.2.2-rc.1、Node.js 24.9+、Python 3.8+。安装后重启对应 profile。DSH Desktop 请替换为实际使用的 profile 名称。

首次使用：“使用 Alaya，在 D:/Alaya知识库 初始化知识库，带示例卡，不启用语义记忆。”
